# Vulpy Storefront Core

Use this skill for the customer's own local Next.js storefront.

- Inspect and improve storefront components, styles, accessibility, SEO, and
  checkout UX.
- Connect UI changes to the existing Medusa/Payload interfaces.
- Preserve the current design system and responsive behavior unless the
  operator explicitly requests a redesign.
- Run storefront tests, typecheck, and a production build after meaningful
  changes.
- Verify important routes in the local browser or with local HTTP checks.
- Keep credentials, customer data, private infrastructure, and internal
  implementation history out of responses and committed files.
