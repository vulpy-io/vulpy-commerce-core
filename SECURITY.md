# Security

Vulpy Commerce takes security seriously.

## Reporting a vulnerability

Please report security issues privately — **do not open a public issue**.
Email `security@vulpy.io` (or use GitHub's private vulnerability reporting
if enabled on this repository). Include:

- affected version/tag
- steps to reproduce
- impact you observed

We aim to acknowledge reports within one business day and will coordinate
a fix + disclosure. Patches are verified against the signed release
(`release-manifest.sig` / `checksums.sha256`).
